# Medidhisubbaiah Trust Website

A modern, responsive, and dynamic web application for **Medidhisubbaiah Trust** — a non-profit social-service organization dedicated to community welfare, free vocational training, emergency healthcare, educational support, and youth development.

Inspired by the design architecture of [Sri Shree Vision Foundation](https://www.srishreevisionfoundation.org/).

---

## 🌿 Key Features

- **White & Green Aesthetic**: Emerald (`#059669`) & Deep Teal (`#0F6E6E`) theme with crisp typography using Google Fonts (**Outfit** for Headings and **Inter** for Body).
- **Live Marquee Announcement Ticker**: Real-time ticker broadcasting free training admissions, 24/7 blood helpline, and welfare drives.
- **Top Bar & 24/7 Emergency Blood Helpline**: Quick access with live pulsing indicator.
- **Animated Hero Carousel**: Multi-slide banner with Ken Burns zoom effect and dual action CTAs.
- **4 Overlapping Feature Cards**: Quick access to Tailoring, Blood Helpline, Annadhanam, and Education & Sports.
- **9 Core Community Services / Causes**:
  1. Free Tailoring Training Program
  2. Free Muggam/Maggam Work Program
  3. Free Certificate Distribution Ceremonies
  4. 24/7 Voluntary Blood Donation & Helpline
  5. Free Food Distribution (Annadhanam)
  6. Free Monthly Grocery Ration Distribution
  7. Summer Chalivendram Drinking Water & Buttermilk Kiosks
  8. Youth Sports Tournaments & Free Sports Kits
  9. Educational Kits & Merit Scholarships
- **Interactive Online Donation & Volunteer Modal**:
  - Quick donation amounts (`₹500`, `₹1000`, `₹2500`, `₹5000`, and custom amount).
  - Direct **UPI ID** with one-click copy (`medidhisubbaiah@sbi`).
  - Official Bank Account & IFSC details with **80G Tax Exemption** compliance note.
- **Interactive Modals**: Service application modal, Event RSVP registration, News reader, and Fullscreen Photo Lightbox.
- **Floating Action Hub**:
  - Floating **WhatsApp Helpline** button.
  - Floating **24/7 Emergency Blood Call** button with animated pulse.
  - Smooth **Scroll-to-Top** button.
- **Admin Management Hub**:
  - Secure credential authentication.
  - Full CRUD operations for Services, Events, News, Photo Gallery, and Contact Inquiries.
  - LocalStorage persistence with instant sync.

## 🚀 Getting Started

### Local Setup:
Simply open `index.html` in any modern browser, or run a local HTTP server:

```bash
# Using Python
python -m http.server 3000

# Using Node / npx
npx serve .
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
